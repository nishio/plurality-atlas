什麼是公民科技（Civic Tech）？

市民親手運用科技，與行政機關合作解決地方與社會的問題，或讓政治參與變得更容易的活動。美國的 Code for America、臺灣的 g0v、日本的 Code for Japan 是代表例子。

災害發生時，想用地圖知道哪裡缺什麼；想讓政府的手續更好懂。有一股潮流是：這些困擾不只交給政府，而是由市民用自己的技術解決。這就是公民科技。

一句話說明

公民科技（Civic Tech）是把「公民」（civic）與「科技」（technology）合在一起的詞。指一般市民用技術解決自己城鎮或社會的困擾，或讓參與行政變得更容易的活動[1]。

參與的不只是工程師，還有行政職員、設計師、在地居民等各式各樣的人[1]。

舉例來說

sinsai.info 與 Code for Japan（日本，2011 年～）。 根據英文版《Plurality》，帶領日本公民科技的關治之（Hal Seki），在 2011 年東日本大地震之後，主導建立了收集災情資訊並標在地圖上的網站 sinsai.info，後來創立了 Code for Japan[2]。

關治之自己回顧，原本是對社會課題不感興趣的工程師。在參與 sinsai.info 的過程中，開始思考技術是否真能讓人幸福，並認為開源（以任何人都能使用、改良的形式公開）的營運方式，正是地方政府所需要的[3]。Code for Japan 也以開源方式打造了東京都的新冠肺炎防疫網站[1]。

g0v 與口罩地圖（臺灣，2012 年～）。 根據中文維基百科，「臺灣的公民科技社群以『g0v零時政府』為代表」，g0v 社群發起的專案，「例如政府預算視覺化，以及2020年COVID-19疫情期間串接政府開放資料而生的『口罩地圖』，讓民眾即時查詢各藥局口罩存量」[4]。→〈g0v（零時政府）〉

根據關治之的報告，到 2020 年 2 月 8 日為止，g0v 的網站上列出了 28 個地圖應用程式、14 個 LINE 應用程式等。基礎是政府把透過健保卡 IC 晶片掌握的銷售資料，每 30 秒公開一次[5]。

Code for America（美國，2009 年～）。 鈴木健在日文版《PLURALITY》的解說中整理道：2009 年美國成立了 Code for America，受其影響，2013 年日本誕生了 Code for Japan，2014 年德國誕生了 Code for Germany[6]。

運作方式

公民科技與政府科技

關治之的 FAQ（2021 年）把公民科技定義為：市民自己用技術解決課題的活動、推動市民參與公共場域的活動，以及用技術改善民主本身的活動[1]。

與它區分開來的是「政府科技」（GovTech），指行政機關用技術改善自己的工作。兩者有許多重疊之處，Code for Japan 也在做給行政職員的研修等政府科技的事業[1]。中文維基百科也寫道：「公民科技 Civic Tech 與治理科技 GovTech 的差別在於公民科技的受眾為民眾，而治理科技的受眾為政府」，兩者的目標都是加強市民與政府的互動[4]。

關治之在 2025 年的投影片中總結：公民科技的「科技」只是手段，真正的目的是實現大家都參與的更好的民主；只是因為數位技術大幅降低了參與的成本，才讓新的做法成為可能[7]。

跨國的連結

g0v 的官方 FAQ，把英國的 mySociety、美國的 Code for America 與 Sunlight Foundation 列為相似的海外團體[8]。g0v 的高嘉良（clkao）在 2017 年的訪談中說，臺灣也加入了各國公民科技團體的網絡「Code for All」；因為 g0v 是鬆散的社群、無法投票，所以由另一個基金會擔任窗口[9]。

日本的形態

根據關治之，日本以地區為單位的「Code for ○○」聚會超過 70 個；關治之寫道，這麼多的大概只有美國和日本（2021 年的 FAQ 則說超過 90 個）[10][1]。

關治之回顧，10 年前有人說，日本人的公民意識薄弱、凡事交給政府的心態很強，所以不可能；但公民科技以日本自己的形式扎根了。關治之並主張，公民科技不是技術或商業模式，而是無法靠上而下的命令產生、由下而上的「文化」[11]。參與者中工程師約占 3 成[1]。

新的浪潮 — 數位民主

關治之也報告了新的潮流：從公民團體 DD2030 誕生的広聴AI、在西班牙巴塞隆納誕生的公民參與工具 Decidim，以及廣泛傾聽（廣泛聽取大量聲音並加以整理）等陸續出現；與過去的公民科技族群不同、關心討論與對話的人們開始聚集[10]。這些公民參與工具也開始成為公司的事業[10]。

爭議與批評

  • 「市民會自動幫忙解決」是幻想。 對於從地方政府負責人那裡一再聽到的這種期待，關治之根據 13 年的經驗斷言那是「幻想」。關治之說，Code for America 之所以能成立，是因為有來自基金會的大筆資金；Code for Japan 能延續，也是因為能把面向地方政府的事業利潤，挹注到夥伴的活動上。關治之也寫道，工具的原型可以靠志工做出來，但無法像企業那樣持續營運[10]。
  • 由行政主導時會發生的事。 關治之的投影片指出，由行政主導時，預算比較容易到位，但容易發生手段變成目的、市民變得被動、預算用完或負責人調動就停擺等情況。投影片也寫道，不能把市民看成解決行政課題的工具[7]。
  • 這不是「工程師的活動」。 關治之說，在日本，很多人因為「我不是工程師」而對參與或擔任領導者有所顧慮。海外團體的領導者常常不是技術人員，應該從思考城鎮的理想樣貌開始[10]。
  • 成果要怎麼衡量？ 關治之指出，大家對產生新服務的期待太大，卻沒有評估工作方式的改善與信任建立的方法[10]。

在《Plurality》中的位置

《多元宇宙》3-3 章〈我們遺忘的道〉寫道：「或許與我們通往⿻之路最切身相關的是，藉加強政府和民主公民社會的數位參與，進而復興早期網際網路的公共和多元精神與理想的運動。這些『政府科技』（GovTech）與『公民科技』（Civic Tech）運動，利用開源軟體式的開發實踐來改善政府服務的提供，並以更為多樣化的方式將公眾帶入此一過程。」[12]

同一章舉出的先驅，是 Code for America 的創始人 Jennifer Pahlka 和 Beth Simone Noveck[12]。英文版還列出了關治之，並寫道這些例子雖然有重要的影響，卻難以像 g0v 在臺灣那樣產生全國可見的影響（目前的繁體中文版沒有關治之，這一句的寫法也不同）[2][12]。

2-2 章把 g0v 描寫為最能象徵臺灣公民社會基礎的運動，並稱其發起人為「公民黑客」[13]。臺灣的歷程在〈臺灣的數位民主〉與〈vTaiwan〉中介紹。
