⿻多元宇宙地圖
日本語 English 简体中文

什麼是開源（open source）？

把軟體的設計圖（原始碼）公開，讓任何人都能使用、研究、修改、再散布的開發方式。《多元宇宙》把它視為⿻的大型實踐，也把投入者幾乎拿不到資金列為政策上的課題。

軟體有一份人能讀、也能改寫的「設計圖」，叫做原始碼。把它公開，讓全世界任何人都能使用、修改、再散布，這樣的開發方式就是開源。《多元宇宙》在這裡看到了不同的人彼此協作的社會的範本。

一句話說明

開源（open source）是把軟體的原始碼公開，讓任何人都能使用、研究、修改、再散布的開發方式。有共同興趣的人在彼此的工作上繼續堆疊；意見談不攏時，就「分叉」（fork）出另一個版本[1]。

《多元宇宙》把它看成⿻（Plurality：不同的人跨越差異而協作）的大規模實踐[1]。同時，書也把投入者幾乎拿不到資金這件事，列為政策上的課題[2]。

舉例來說

這本書本身。 《多元宇宙》繁體中文版的〈關於作者群〉寫道：「這本書是開源的，其內容可以自由複製，無論是否註明出處。」[3] 根據書的 5-0 章，文稿使用開源工程師用來管理軟體版本的 Git 儲存與更新，並以 CC0（放棄著作權、讓任何人都能自由使用的宣告）公開[4]。英文版還寫道，貢獻的紀錄透過名為 GitRules 的機制，留在分散式帳本上[4]。

同一章呼籲讀者：如果受到內容啟發，尤其是有所批判之處，歡迎提交修改，或聯繫貢獻者、成為社群的一分子。書寫道：「我們希望盡可能的讓對這項工作的批評，可從開源運動的口號『那就修正它吧！』受到啟發。」[4]（英文版的口號原文是 "so fix it!"。）

vTaiwan 與 Join。 臺灣有公民主導的審議平台 vTaiwan，以及政府經營的提案與意見徵集平台 Join[5]。2018 年，曾于珊在對談中問唐鳳（Audrey Tang），為什麼 vTaiwan 是開源軟體，Join 卻不是。唐鳳回答，Join 是「2014年底開始的專案、2015年招標，所以當時臺灣的資訊軟體採購範本裡面，還沒有Open Source的段落」[6]。

Gitcoin Grants（資金）。 書的 5-7 章寫道，由於軟體是免費提供的，開源軟體「長期以來一直在努力尋求可靠的資金來源」[7]。書接著介紹 GitCoin Grants 等平台：它們使用的公式「不僅考慮所獲資金的總額，也考慮其來源在個人貢獻者和相關社會群體中的多樣性」，並已成為開源軟體的重要資金來源[7]。繁體中文版寫這些平台「籌集了數億美元的資金」，英文版則寫總共超過一億美元[7]。

深入了解

從哪裡來

根據書的 3-3 章，開源的出現，是對 1970 年代軟體產業走向營業秘密化、商業化的反擊[1]。書寫道，網際網路的前身 ARPANET 早期那種自由、開放的開發方式，在公共資金撤出後，靠著全球的志願者得以維持[1]。

理查·史托曼（Richard Stallman）自 1980 年代起領導自由軟體運動，推廣使用者運行、研究、共享和修改原始碼的權利[1]。1998 年，開源倡議組織（Open Source Initiative）把其中務實的面向命名為「開源」[1]。

三種叫法

唐鳳會區分指稱同一件事的幾種說法。在 2018 年的對談中，唐鳳說：「如果使用Free Software這個詞，通常的意思是這是一種人權，使用、改作軟體的權利不應該被剝奪」；說 Open Source 時，指的則是開發過程中越多人參與、越透明，品質就會越好，「所以一個是倫理或道德論述，一個是經濟論述」[6]。不過唐鳳也說，「這兩種授權的實質涵義幾乎完全一樣」[6]。

在 2024 年的 Podcast《Tech Mirror》中，唐鳳說明，在臺灣稱之為公共程式（public code），意思是把程式碼當作機場、車站那樣的公共基礎建設[8]。在 2023 年的演講中，唐鳳提到主張用稅金開發的系統都應該公開的運動「Public Money? Public Code!」，並說臺灣已說服內閣，把程式碼和橋梁、高速公路一樣，列為公共建設預算的對象[9]。

作為⿻的範本

3-3 章把開源連曾經敵對的公司也支持、因而擴展開來這件事，稱為「大規模的多元化實踐」[1]。書舉的例子是微軟：繁體中文版寫它「現為 GitHub 的所有者」，英文版另外寫到，微軟也是本書作者之一的雇主[1]。

書關注的是協作的形式：「這些社群是圍繞著共同的興趣而形成，在彼此的工作基礎上自由構建，通過無償維護者審核貢獻，並在出現不可調和的分歧時，將專案『分叉』為平行版本。」[1] 英文版的 4-3 章把開源專案當作例子：多人協作往往產生比各自單獨行動更大的價值，做出來的東西也由許多人共同使用；書認為，在這樣的場合，以金錢為基礎的管理難以運作[10]。

錢流不進來

3-3 章引用娜蒂亞·埃格巴爾（Nadia Eghbal）的《Working in Public》，列出開源面臨的挑戰：公共資金撤離造成長期的資金短缺、維護者往往得不到回報、社群越成長負擔越重。儘管如此，書寫道：「這些挑戰都是可以應對的」[1]。

2-0 章寫道，開源軟體和維基百科這些具有公地性的公共產品，已成為數位時代至關重要的公共資源，「卻未見各國政府支持它們，它們得到的支持甚至無法與其他慈善組織相提並論。（例如，開源軟體供應商通常不能成為享有免稅的慈善機構。）」[11]

7-0 章寫道，當今最被各國政府忽視的不是學術部門，而是開源和其他非營利、以使命為導向的技術開發者[2]。繁體中文版寫，學研在全球範圍內獲得了數千億美元的資助，「但開源社群在其整個歷史中獲得的資助，可能還不到十億美元」；日文版也寫不到十億美元[12]。英文版則寫學術研究每年在全球獲得數千億美元，並依已知的資金來源計算，開源社群獲得的可能不到二十億美元（各版的數字不同）[2]。

與其說「公共財」，不如說「開源」

以太坊創辦人維塔利克·布特林（Vitalik Buterin）在 2025 年的文章中主張，談資金時，用「開源」這個詞比用「公共財」更好[13]。理由是：「公共財」也被用來指政府做的東西，連擁有自己代幣（一種加密資產）的商業專案都自稱在做公共財，意思已經被稀釋；相較之下，「開源」有一個延續數十年的明確定義[13]。

同一年，布特林也寫了一篇文章說，以前因為希望自己的作品盡可能被廣泛使用等理由，偏好條件寬鬆的授權，現在則傾向 copyleft（要求修改後的版本也以相同條件公開的方式）[14]。

數位公共財

日文書《廣泛傾聽》（原書名《政治・自治体・企業に広がるブロードリスニング》，談廣泛聽取市民聲音的做法）中，有一篇由 tokoroten 執筆的專欄。專欄介紹，聯合國在 2020 年把開源的軟體、資料、AI 模型、標準與內容定義為「數位公共財」，條件是遵守隱私等法規、不造成傷害，並有助於聯合國的永續發展目標（SDGs）[15]。

同一篇專欄也提到，日本情報處理推進機構（IPA）2025 年的報告指出，日本行政機關公開的開源軟體遠少於英、美、法。專欄並認為真正的成本在於能運用它的人才，寫道數位公共財雖然免費，卻不是零成本[15]。

爭議與批評

AI 也該開放嗎？ 書的 7-0 章寫道，開發生成式基礎模型的組織，如 OpenAI 和 Anthropic，「對簡單地免費提供這些模型有合理的擔憂」[2]。

唐鳳在 2024 年的 Podcast《Your Undivided Attention》中說，技術越接近醫療口罩那樣的防禦工具，就越應該公開；越接近被稱為 P3 的實驗室可能製造、致死率極高的東西，就越應該在公開前要求規範、演練與稽核。唐鳳也說，也許有些東西根本不應該公開[16]。另外，在同一集中表示民主應該能把強大的 AI 模型重新調整成強化民主的樣子、而開源與開放權重對此很有幫助的，並不是唐鳳，而是主持人 Aza Raskin；Raskin 先說這是自己認為唐鳳所秉持的原則，才這樣表述[16]。

哲學家尼克·伯斯特隆姆（Nick Bostrom）在 2017 年的論文中認為，AI 開發的開放，短期內可望對社會利多於弊。另一方面，論文主張，原始碼和科學（可能也包括能力）的開放，可能讓高等 AI 出現時的競爭更加膠著，使一邊採取安全措施、一邊贏得競爭變得更難。論文也寫道，安全措施或目標的開放，無論是為了當代的人，還是為了包括未來世代在內的福祉，都可以被看作好事[17]。

認為開源不安全、只是省錢的看法。 在 2024 年的《Tech Mirror》中，主持人說，臺灣每天承受來自中國的網路攻擊，這樣的經驗推翻了開源不可能安全的迷思。唐鳳回答，公共程式不是為了省錢；一開始反而要培養懂得運用它的實務者社群，所以花費更多[8]。上面那篇專欄說數位公共財免費卻不是零成本，也是同一方向的提醒[15]。

不是夢想，而是實用。 在 2019 年的訪談中，被問到矽谷那個開源而自由的網際網路的夢想是否還活著時，唐鳳回答，開源不是夢想，而是非常實用的東西，並舉例說微軟改變方針、擁有了 GitHub，Google 沒有 Linux 就不會存在[18]。

資金的數字是推估。 7-0 章的英文版說，不到二十億美元這個數字，是根據 GitHub Sponsors、Gitcoin、Open Collective 等已知資金來源匯集成的圖，並用了 likely（可能）一詞[2]。繁體中文版「可能還不到十億美元」也帶著「可能」[12]。

在《Plurality》中的位置

《多元宇宙》3-3 章〈我們遺忘的道〉把開源當作範本，說明打造網際網路的人們那種開放協作的精神至今仍在延續。英文版因此說本書會經常以開源專案為例；繁體中文版則寫「開源軟體將成為本書的核心實例」[1]。

5-7 章〈社會市場〉以開源的資金問題與 GitCoin Grants 開頭[7]。7-0 章〈政策〉描繪，如果⿻取得成功，十年內公共資金將成為支持數位基礎建設的主要資金來源[2]。同一章也寫道，在公益、由公民社會推動的技術開發能做到什麼這一點上，「開源社群只是冰山一角」，因為像 Mozilla 和維基媒體基金會這樣的組織，在純粹的開源程式開發之外，也有大量的開發活動[12]。

其他章節也有例子。6-4 章把臺灣的開源環境感測網絡社群 LASS，6-5 章把收錄國語、台語、客語條目的「萌典」，都舉為開源協作的例子[19][20]。
