ID と人物性（⿻ ID）ってなに？

ネットで「私は私です」と示す方法を、パスワードや一つの番号・指紋に頼らず、「この人を知っている」と言ってくれる多くの人や組織の重なりで支えよう、という考え方です。身元を示しやすく、しかも一か所から全部を覗かれにくくなる、と本『Plurality』は主張します。

ネットのサービスに登録するとき、私たちはメールアドレスやパスワード、ときには顔写真や指紋を差し出します。便利ですが、それを握った会社や役所は、私たちの行動をまとめて見られるようになるかもしれません。「自分が自分であること」を示しつつ、のぞかれすぎないようにするにはどうすればよいのか。ID と人物性（⿻ ID）は、この問いへの本『⿻ Plurality』の答えです。

ひとことで言うと

ネットで「私は私です」と示す方法を、パスワードや一つの番号・指紋に頼るのではなく、「この人を知っている」と言ってくれる多くの人や組織の重なりで支えよう、という考え方です。学校、職場、友人、役所などがその例です。

本は、こうすると身元を示しやすく、しかも一か所から全部をのぞかれにくくなる、と主張します[1][2]。「人物性」とは、ここでは「一人の人として認められること」を指します。

たとえば

インドの Aadhaar（アーダール）。 インド政府のデジタル基盤の一部で、顔写真、両目の虹彩（目の模様）、10 本の指紋を登録するしくみです。人口の 99% を超える人が加入しました。本は、規模・誰も取り残さないこと・安全性の点で世界有数だと評価します。そのうえで、生体情報を日々の本人確認に使うと、運営する側が市民の活動を横断的に見られるようになる、と指摘します。イスラム教徒の少数派について、活動家がそれを心配しているそうです。インドの最高裁判所は、民間での利用を制限しました[3]。

Worldcoin（ワールドコイン）。 OpenAI の共同創業者サム・アルトマンらが 2019 年に始めた、「オーブ」という機械で虹彩を読み取る世界規模の ID です。本は、生体情報を最初の登録だけに使えばプライバシーは守れるが、アカウントを盗まれたり売られたりしやすく、「ただ一人の人間であること」以外は何も示せない、と批判します[4]。くわしくは 人間であることの証明 の記事をどうぞ。

ソーシャルリカバリ。 鍵（パスワードのようなもの）をなくしたとき、「5 人のうち 3 人の友人や機関」が同意すれば取り戻せる、というやり方です。本は、Web3（ブロックチェーンを使う新しいネットのしくみ）の世界で標準になり、Apple も取り入れ始めたと紹介し、Plurality らしい ID の取り戻し方だとしています[5]。

くわしく

示すことと、守ることのジレンマ

本（第 4-1 章）は、ID のしくみの価値は「どれだけしっかり本人だと示せるか」で決まると言います。でも、いちばん単純な示し方（パスワードを見せるなど）は、見せたとたんに盗まれる危険を生みます。だから ID のしくみでは、個人の情報を守ること自体が役に立つことの中心であり、「示す」と「守る」を同時にこなせるかで評価すべきだ、と本は書きます[6]。

今の ID は、どれも一長一短

本は、今ある ID をこう整理します[7]。

  • 国の ID は正統ですが、いろいろな場面で使い回されて秘密にできず、出生証明のような薄い情報に基づいています。
  • 大手 IT 企業の「〜でログイン」 は便利ですが、一つの会社が私たちの行動の全体を握ります。
  • 広告会社や信用スコアの会社 は、私たちのくわしい情報を持っていますが、見えないところで動いています。
  • 小さな地元の ID（学歴、職業の団体、宗教の団体、ゲームの中の名前など）は自然で信頼できると感じられますが、ばらばらで使いにくいものです。

特定の会社に頼らない新しい ID の技術もありますが、鍵を誰の助けも借りずに管理したり、なくしたときに取り戻したりする方法がまだ確立していない、と本は書きます[8]。

「重なり」としての ID

本の答えは、人を生き物としてではなく、社会の中の存在として捉えることです。私たちが誰かを思い浮かべるとき、それは顔や体つきより、「一緒にしたこと、行った場所、その人のふるまい」によります。本はこれを「ソシオメトリクス（社会的な情報で人を知ること）」と呼びます[9]。

本は、この考え方の利点を五つにまとめます[9]。

  1. 漏れがなく、予備もある。 たくさんの関係があるので、一つが欠けても困りません。
  2. プライバシー。 互いに知っている事実を共有するだけなので、見張られている感じがしません。
  3. 段階的に確かめられる。 保証してくれる人を増やすほど、確かさが上がります。
  4. 弱点が一か所に集まらない。 一つが破られても全部は崩れません。
  5. 取り戻せる。 互いに示し合わせそうにない別々の人たちが一緒に、なくした ID を取り戻せます。

どう回すのか

人が安定して保てる関係は約 150 人と言われます（ダンバー数）。だから支えが要る、と本は言います[10]。本は二つの形を挙げます。一つは、中くらいの規模の確認役の組織をたくさん置く形です。もう一つは、「友だちの友だち」をたどって信頼をつなぐ形です。本は、100 億人がそれぞれ 100 の確認役の組織と関係を持つという数の例で、所属がでたらめに分かれていても 300 の確認役が共存でき、現実にはもっと多く、たとえば 10 万ほどまでありうる、と見積もっています。そして両方を組み合わせれば、使えて、しかも私的な ID の世界がつくれる、と論じます[10]。

ID は「集まり」の問題でもある

私たちについての情報のほとんどは、ほかの人も知っていて、ほかの人の情報でもあります。だから守るべきなのは、情報を隠すことより、情報がもともとの文脈にとどまることだ、と本は言います。プライバシー研究者ヘレン・ニッセンバウム（Helen Nissenbaum）が「文脈の完全性」と呼ぶものです[11]。それは集団の決まりを守ること、つまり集まる自由の問題になる、と本は結びます[11]。これは次の章の ⿻ 公衆 につながります。

この考え方は、本より前から、グレン・ワイルらのブログの連載（2019 年）や、ワイル、プジャ・オールハーバー、ヴィタリック・ブテリンの論文（2022 年）でも展開されていました[12][13]。

どこが議論になっているか

  • ブテリンの評価。 イーサリアムの創始者ヴィタリック・ブテリン（Vitalik Buterin）は 2024 年の書評で、本の ID 論の中心を、一つの要素だけに頼る方法はどれも弱すぎるので、いくつもの要素を組み合わせるべきだ、という点にあるとまとめました。取り戻しの仕組みについては、各人が信頼する相手を選び、間違えても影響はその人だけにとどまるので分かりやすい、と認めています。一方、全員に同じお金を配る制度や投票は、共同体の全員についての合意が要るので難しい、と指摘します[14]。
  • 「一人一つの ID」をめぐる対立。 World（旧 Worldcoin）は、一人に一つだけの資格であることが欠かせず、少しでも複数の資格を許せば売り買いされて大きな穴になる、と主張しています[15]。これに対しブテリンは 2025 年、たとえ暗号の技術で中身を隠しても、「一人一つ」を守ろうとすること自体が、プライバシーを失う・強制される・間違えるといった危険を生む、と書きました。そして「多元的な ID」がいちばん現実的な答えだとしています[16]。本も、唯一であることしか示せない生体 ID の限界を批判しています[4]。
  • よくある誤解。 「⿻ ID は生体認証を否定している」わけではありません。会えば相手の顔なども自然に分かるので、社会的な情報には生体情報も含まれうるが、それだけではない、と本は書いています[9]。

Plurality の中での位置

この考え方は、本の第 4 部の最初の各論（4-1 章）です。本の章の要約は、権利のうちいちばん基本的なのは「人物性への権利」だとし、Plurality の見方ではそれが多くの社会的な所属に根ざすデジタル ID として実現される、と書いています[2]。

権利 OS の図でいえば、ID は「点（人）」にあたります。次の章の ⿻ 公衆 は「点を囲む塊（集まり）」で、二つは表裏の関係です。

本の後半の多くの仕組みも、この ID に頼っています。たとえば、人のつながりを考えに入れる ⿻投票 や、利害関係者をたどる 社会市場 です。「ただ一人の人間であること」を示す部分は 人間であることの証明 で扱います。
