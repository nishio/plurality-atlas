什么是公民科技（Civic Tech）？

市民亲手运用科技，与行政机关合作解决地方与社会的问题，或让政治参与变得更容易的活动。美国的 Code for America、台湾的 g0v、日本的 Code for Japan 是代表例子。

灾害发生时，想用地图知道哪里缺什么；想让政府的手续更好懂。有一股潮流是：这些困扰不只交给政府，而是由市民用自己的技术解决。这就是公民科技。

一句话说明

公民科技（Civic Tech）是把「公民」（civic）与「科技」（technology）合在一起的词。指一般市民用技术解决自己城镇或社会的困扰，或让参与行政变得更容易的活动[1]。

参与的不只是工程师，还有行政职员、设计师、在地居民等各式各样的人[1]。

举例来说

sinsai.info 与 Code for Japan（日本，2011 年～）。 根据英文版《Plurality》，带领日本公民科技的关治之（Hal Seki），在 2011 年东日本大地震之后，主导建立了收集灾情资讯并标在地图上的网站 sinsai.info，后来创立了 Code for Japan[2]。

关治之自己回顾，原本是对社会课题不感兴趣的工程师。在参与 sinsai.info 的过程中，开始思考技术是否真能让人幸福，并认为开源（以任何人都能使用、改良的形式公开）的营运方式，正是地方政府所需要的[3]。Code for Japan 也以开源方式打造了东京都的新冠肺炎防疫网站[1]。

g0v 与口罩地图（台湾，2012 年～）。 根据中文维基百科，「台湾的公民科技社群以『g0v零时政府』为代表」，g0v 社群发起的项目，「例如政府预算视觉化，以及2020年COVID-19疫情期间串接政府开放资料而生的『口罩地图』，让民众即时查询各药局口罩存量」[4]。→〈g0v（零时政府）〉

根据关治之的报告，到 2020 年 2 月 8 日为止，g0v 的网站上列出了 28 个地图应用程式、14 个 LINE 应用程式等。基础是政府把透过健保卡 IC 晶片掌握的销售资料，每 30 秒公开一次[5]。

Code for America（美国，2009 年～）。 铃木健在日文版《PLURALITY》的解说中整理道：2009 年美国成立了 Code for America，受其影响，2013 年日本诞生了 Code for Japan，2014 年德国诞生了 Code for Germany[6]。

运作方式

公民科技与政府科技

关治之的 FAQ（2021 年）把公民科技定义为：市民自己用技术解决课题的活动、推动市民参与公共场域的活动，以及用技术改善民主本身的活动[1]。

与它区分开来的是「政府科技」（GovTech），指行政机关用技术改善自己的工作。两者有许多重叠之处，Code for Japan 也在做给行政职员的研修等政府科技的事业[1]。中文维基百科也写道：「公民科技 Civic Tech 与治理科技 GovTech 的差别在于公民科技的受众为民众，而治理科技的受众为政府」，两者的目标都是加强市民与政府的互动[4]。

关治之在 2025 年的幻灯片中总结：公民科技的「科技」只是手段，真正的目的是实现大家都参与的更好的民主；只是因为数位技术大幅降低了参与的成本，才让新的做法成为可能[7]。

跨国的连结

g0v 的官方 FAQ，把英国的 mySociety、美国的 Code for America 与 Sunlight Foundation 列为相似的海外团体[8]。g0v 的高嘉良（clkao）在 2017 年的访谈中说，台湾也加入了各国公民科技团体的网络「Code for All」；因为 g0v 是松散的社群、无法投票，所以由另一个基金会担任窗口[9]。

日本的形态

根据关治之，日本以地区为单位的「Code for ○○」聚会超过 70 个；关治之写道，这么多的大概只有美国和日本（2021 年的 FAQ 则说超过 90 个）[10][1]。

关治之回顾，10 年前有人说，日本人的公民意识薄弱、凡事交给政府的心态很强，所以不可能；但公民科技以日本自己的形式扎根了。关治之并主张，公民科技不是技术或商业模式，而是无法靠上而下的命令产生、由下而上的「文化」[11]。参与者中工程师约占 3 成[1]。

新的浪潮 — 数位民主

关治之也报告了新的潮流：从公民团体 DD2030 诞生的広聴AI、在西班牙巴塞隆纳诞生的公民参与工具 Decidim，以及广泛倾听（广泛听取大量声音并加以整理）等陆续出现；与过去的公民科技族群不同、关心讨论与对话的人们开始聚集[10]。这些公民参与工具也开始成为公司的事业[10]。

争议与批评

  • 「市民会自动帮忙解决」是幻想。 对于从地方政府负责人那里一再听到的这种期待，关治之根据 13 年的经验断言那是「幻想」。关治之说，Code for America 之所以能成立，是因为有来自基金会的大笔资金；Code for Japan 能延续，也是因为能把面向地方政府的事业利润，挹注到伙伴的活动上。关治之也写道，工具的原型可以靠志工做出来，但无法像企业那样持续营运[10]。
  • 由行政主导时会发生的事。 关治之的幻灯片指出，由行政主导时，预算比较容易到位，但容易发生手段变成目的、市民变得被动、预算用完或负责人调动就停摆等情况。幻灯片也写道，不能把市民看成解决行政课题的工具[7]。
  • 这不是「工程师的活动」。 关治之说，在日本，很多人因为「我不是工程师」而对参与或担任领导者有所顾虑。海外团体的领导者常常不是技术人员，应该从思考城镇的理想样貌开始[10]。
  • 成果要怎么衡量？ 关治之指出，大家对产生新服务的期待太大，却没有评估工作方式的改善与信任建立的方法[10]。

在《Plurality》中的位置

《多元宇宙》3-3 章〈我们遗忘的道〉写道：「或许与我们通往⿻之路最切身相关的是，藉加强政府和民主公民社会的数位参与，进而复兴早期互联网的公共和多元精神与理想的运动。这些『政府科技』（GovTech）与『公民科技』（Civic Tech）运动，利用开源软件式的开发实践来改善政府服务的提供，并以更为多样化的方式将公众带入此一过程。」[12]

同一章举出的先驱，是 Code for America 的创始人 Jennifer Pahlka 和 Beth Simone Noveck[12]。英文版还列出了关治之，并写道这些例子虽然有重要的影响，却难以像 g0v 在台湾那样产生全国可见的影响（目前的繁体中文版没有关治之，这一句的写法也不同）[2][12]。

2-2 章把 g0v 描写为最能象征台湾公民社会基础的运动，并称其发起人为「公民黑客」[13]。台湾的历程在〈台湾的数位民主〉与〈vTaiwan〉中介绍。
