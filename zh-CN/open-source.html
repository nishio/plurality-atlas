什么是开源（open source）？

把软件的设计图（原始码）公开，让任何人都能使用、研究、修改、再散布的开发方式。《多元宇宙》把它视为⿻（Plurality：不同的人跨越差异而协作）的大型实践，也把投入者几乎拿不到资金列为政策上的课题。

软件有一份人能读、也能改写的「设计图」，叫做原始码。把它公开，让全世界任何人都能使用、修改、再散布，这样的开发方式就是开源。《多元宇宙》在这里看到了不同的人彼此协作的社会的范本。

一句话说明

开源（open source）是把软件的原始码公开，让任何人都能使用、研究、修改、再散布的开发方式。有共同兴趣的人在彼此的工作上继续堆叠；意见谈不拢时，就「分叉」（fork）出另一个版本[1]。

《多元宇宙》把它看成⿻（Plurality：不同的人跨越差异而协作）的大规模实践[1]。同时，书也把投入者几乎拿不到资金这件事，列为政策上的课题[2]。

举例来说

这本书本身。 《多元宇宙》繁体中文版的〈关于作者群〉写道：「这本书是开源的，其内容可以自由复制，无论是否注明出处。」[3] 根据书的 5-0 章，文稿使用开源工程师用来管理软件版本的 Git 储存与更新，并以 CC0（放弃著作权、让任何人都能自由使用的宣告）公开[4]。英文版还写道，贡献的纪录透过 GitRules（旧名 Gov4Git，在 Git 上记录并运作「谁贡献了多少、采用哪些修改」的开源工具），留在分散式帐本（由参与者各自保存同一份纪录的帐本）上[4]。

同一章呼吁读者：如果受到内容启发，尤其是有所批判之处，欢迎提交修改，或联系贡献者、成为社群的一分子。书写道：「我们希望尽可能的让对这项工作的批评，可从开源运动的口号『那就修正它吧！』受到启发。」[4]（英文版的口号原文是 "so fix it!"。）

vTaiwan 与 Join。 台湾有公民主导的审议平台 vTaiwan，以及政府经营的提案与意见征集平台 Join[5]。在 2018 年的一场对谈中，曾任台湾首任数位发展部部长的唐凤（Audrey Tang）[3]被问到为什么 vTaiwan 是开源软件，Join 却不是。唐凤回答，Join 是「2014年底开始的项目、2015年招标，所以当时台湾的资讯软件采购范本里面，还没有Open Source的段落」[6]。

Gitcoin Grants（资金）。 书的 5-7 章写道，由于软件是免费提供的，开源软件「长期以来一直在努力寻求可靠的资金来源」[7]。书接着介绍 GitCoin Grants 等新的配对平台：它们把赞助者（小额捐赠者和资助者）出的资金，用一个公式来分配，这个公式「不仅考虑所获资金的总额，也考虑其来源在个人贡献者和相关社会群体中的多样性」；这些平台已成为开源软件的重要资金来源[7]。繁体中文版写这些平台「筹集了数亿美元的资金」，英文版则写总共超过一亿美元[7]。

深入了解

从哪里来

根据书的 3-3 章，开源的出现，是对 1970 年代软件产业走向营业秘密化、商业化的反击[1]。书写道，互联网的前身 ARPANET 早期那种自由、开放的开发方式，在公共资金撤出后，靠着全球的志愿者得以维持[1]。

理查·史托曼（Richard Stallman）自 1980 年代起领导自由软件运动，推广用户运行、研究、共享和修改原始码的权利[1]。1998 年，开源倡议组织（Open Source Initiative）把其中务实的面向命名为「开源」[1]。

三种叫法

唐凤会区分指称同一件事的几种说法。在 2018 年的对谈中，唐凤说：「如果使用Free Software这个词，通常的意思是这是一种人权，使用、改作软件的权利不应该被剥夺」；说 Open Source 时，指的则是开发过程中越多人参与、越透明，品质就会越好，「所以一个是伦理或道德论述，一个是经济论述」[6]。不过唐凤也说，「这两种授权的实质涵义几乎完全一样」[6]。

在 2024 年的 Podcast《Tech Mirror》中，唐凤说明，在台湾称之为公共程式（public code），意思是把程式码当作机场、车站那样的公共基础建设[8]。在 2023 年的演讲中，唐凤提到主张用税金开发的系统都应该公开的运动「Public Money? Public Code!」，并说台湾已说服内阁，把程式码和桥梁、高速公路一样，列为公共建设预算的对象[9]。

作为⿻的范本

3-3 章把开源连曾经敌对的公司也支持、因而扩展开来这件事，称为「大规模的多元化实践」[1]。书举的例子是微软：繁体中文版写它「现为 GitHub 的所有者」（GitHub 是开源开发者聚集的大型服务），英文版另外写到，微软也是本书作者之一的雇主[1]。

书关注的是协作的形式：「这些社群是围绕着共同的兴趣而形成，在彼此的工作基础上自由构建，通过无偿维护者审核贡献，并在出现不可调和的分歧时，将项目『分叉』为平行版本。」[1] 英文版的 4-3 章把开源项目当作例子：多人协作往往产生比各自单独行动更大的价值，做出来的东西也由许多人共同使用；书认为，在这样的场合，以金钱为基础的管理难以运作[10]。

钱流不进来

3-3 章引用娜蒂亚·埃格巴尔（Nadia Eghbal）探讨开源软件如何被制作与维护的书《Working in Public》（2020），列出开源面临的挑战：公共资金撤离造成长期的资金短缺、维护者往往得不到回报、社群越成长负担越重。尽管如此，书写道：「这些挑战都是可以应对的」[1]。

2-0 章写道，开源软件和维基百科这些具有公地性的公共产品（即公共财。经济学用语，指像路灯、灯塔那样，有人使用也不会减少别人能用的份，也无法把不付钱的人排除在外的东西[11]），已成为数位时代至关重要的公共资源，「却未见各国政府支持它们，它们得到的支持甚至无法与其他慈善组织相提并论。（例如，开源软件供应商通常不能成为享有免税的慈善机构。）」[12]

7-0 章写道，当今最被各国政府忽视的不是学术部门，而是开源和其他非营利、以使命为导向的技术开发者[2]。繁体中文版写，学研在全球范围内获得了数千亿美元的资助，「但开源社群在其整个历史中获得的资助，可能还不到十亿美元」；日文版也写不到十亿美元[13]。英文版则写学术研究每年在全球获得数千亿美元，并依 GitHub Sponsors、Gitcoin、Open Collective 等已知资金来源汇集成的图推估，开源社群获得的可能（likely）不到二十亿美元（各版的数字不同）[2]。

与其说「公共财」，不如说「开源」

以太坊创办人维塔利克·布特林（Vitalik Buterin）在 2025 年的文章中主张，谈资金时，用「开源」这个词比用「公共财」更好[14]。理由是：「公共财」也被用来指政府做的东西，连拥有自己代币（一种加密资产）的商业项目都自称在做公共财，意思已经被稀释；相较之下，「开源」有一个延续数十年的明确定义[14]。

同一年，布特林也写了一篇文章说，以前因为希望自己的作品尽可能被广泛使用等理由，偏好条件宽松的授权，现在则倾向 copyleft（要求修改后的版本也以相同条件公开的方式）[15]。

数位公共财

日文书《广泛倾听》（原书名《政治・自治体・企業に広がるブロードリスニング》，谈广泛听取市民声音的做法）中，有一篇由 tokoroten（中山心太）执笔的专栏。专栏介绍，联合国在 2020 年把开源的软件、资料、AI 模型、标准与内容定义为「数位公共财」，条件是遵守隐私等法规、不造成伤害，并有助于联合国的永续发展目标（SDGs）[11]。

同一篇专栏也提到，日本资讯处理推进机构（IPA）2025 年的报告指出，日本行政机关公开的开源软件远少于英、美、法。专栏并认为真正的成本在于能运用它的人才，写道数位公共财虽然免费，却不是零成本[11]。

争议与批评

AI 也该开放吗？ 书的 7-0 章写道，开发生成式基础模型的组织，如 OpenAI 和 Anthropic，「对简单地免费提供这些模型有合理的担忧」[2]。

在 2024 年的 Podcast《Your Undivided Attention》中，主持人 Aza Raskin 先说这是自己认为唐凤所秉持的原则，然后这样表述：民主应该能把强大的 AI 模型重新调整成强化民主的样子，而模型开源、开放权重（公开到任何人都能重新调整的形式）对此很有帮助。接着 Raskin 也说，开放模型的扩散，反而对资讯系统开放的民主国家伤害更大，并问该在什么时候公开、什么时候保留[16]。唐凤以疫情作比喻回答：技术越接近医疗口罩那样的防御工具，就越应该公开；越接近致死率极高的东西，就越应该在公开前要求规范、演练与稽核。也许有些东西根本不应该公开[16]。

哲学家尼克·伯斯特隆姆（Nick Bostrom）在 2017 年的论文中认为，AI 开发的开放，短期内可望对社会利多于弊。另一方面，论文主张，原始码和科学（可能也包括能力）的开放，可能让高等 AI 出现时的开发竞争更加胶着，使「一旦采用会造成延迟或限制性能的安全措施，就赢不了竞争」的情况更容易发生。论文也写道，安全措施或目标的开放，无论是为了当代的人，还是为了包括未来世代在内的福祉，都可以被看作好事[17]。

认为开源不安全、只是省钱的看法。 在 2024 年的《Tech Mirror》中，主持人说，台湾每天承受来自中国的网络攻击，这样的经验推翻了开源不可能安全的迷思。唐凤回答，公共程式不是为了省钱；一开始反而要培养懂得运用它的实务者社群，所以花费更多[8]。上面那篇专栏说数位公共财免费却不是零成本，也是同一方向的提醒[11]。

不是梦想，而是实用。 在 2019 年的访谈中，被问到矽谷那个开源而自由的互联网的梦想是否还活着时，唐凤回答，开源不是梦想，而是非常实用的东西，并举例说微软改变方针、拥有了 GitHub，Google 没有开源作业系统（让电脑运作的基本软件）Linux 就不会存在[18]。

在《Plurality》中的位置

《多元宇宙》3-3 章〈我们遗忘的道〉把开源当作范本，说明打造互联网的人们那种开放协作的精神至今仍在延续。英文版因此说本书会经常以开源项目为例；繁体中文版则写「开源软件将成为本书的核心实例」[1]。

5-7 章〈社会市场〉以开源的资金问题与 GitCoin Grants 开头[7]。7-0 章〈政策〉描绘，如果⿻取得成功，十年内公共资金将成为支持数位基础建设的主要资金来源[2]。同一章也写道，在公益、由公民社会推动的技术开发能做到什么这一点上，「开源社群只是冰山一角」，因为像 Mozilla 和维基媒体基金会这样的组织，在纯粹的开源程式开发之外，也有大量的开发活动[13]。

其他章节也有例子。6-4 章把台湾的开源环境感测网络社群 LASS，6-5 章把收录国语、台语、客语条目的「萌典」，都举为开源协作的例子[19][20]。
