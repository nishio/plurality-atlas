シビックテックってなに？

市民が自分たちの手でテクノロジーを使い、行政と組んで地域や社会の問題を解いたり、政治に参加しやすくしたりする活動です。米国の Code for America、台湾の g0v、日本の Code for Japan が代表例です。

災害のとき、どこで何が足りないのかを地図で知りたい。役所の手続きをもっとわかりやすくしたい。そうした困りごとを、役所に任せるだけでなく、市民が自分たちの技術で解いてしまおう、という動きがあります。それがシビックテックです。

ひとことで言うと

シビックテック（Civic Tech）は、「市民（シビック）」と「テクノロジー」を合わせた言葉です。ふつうの市民が技術を使って、自分たちのまちや社会の困りごとを解いたり、行政への参加をしやすくしたりする活動を指します[1]。

関わるのはエンジニアだけではありません。行政の職員、デザイナー、地域の人など、さまざまな人が参加します[1]。

たとえば

sinsai.info と Code for Japan（日本、2011 年〜）。 本『Plurality』によれば、日本のシビックテックを率いる関治之（せき・はるゆき、Hal Seki）は、2011 年の東日本大震災のあと、被災の情報を集めて地図に載せるサイト sinsai.info の立ち上げを主導しました。のちに Code for Japan を作っています[2]。

関自身は、もとは社会の課題に関心のないエンジニアだったと振り返ります。sinsai.info に関わる中で、技術は本当に人を幸せにするのか、と考えるようになりました。そして、オープンソース（誰でも使え、改良できる形で公開すること）の運営のやり方こそ自治体に必要だ、と思うようになったといいます[3]。Code for Japan は、東京都の新型コロナウイルス感染症対策サイトもオープンソースで作りました[1]。

g0v とマスク地図（台湾、2012 年〜）。 中国語版ウィキペディアによれば、台湾のシビックテックを代表するのが g0v（ガヴゼロ）です。政府の予算を見える化する取り組みや、2020 年のコロナ禍で、薬局ごとのマスクの在庫を調べられるようにした「マスク地図」が知られています[4]。

関の報告では、2020 年 2 月 8 日の時点で、g0v のサイトには地図アプリが 28、LINE のアプリが 14 などが並んでいました。土台になったのは、政府が健康保険証の IC チップを通じてつかんだ販売データを、30 秒ごとに公開したことでした[5]。

Code for America（米国、2009 年〜）。 鈴木健は『PLURALITY』日本語版の解説で、2009 年に米国で Code for America ができ、その影響で 2013 年に日本で Code for Japan、2014 年にドイツで Code for Germany が生まれた、と整理しています[6]。

しくみ

シビックテックとガブテック

関の FAQ（2021 年）は、シビックテックを、市民自身が技術で課題を解く活動、公共の場への市民の参加を進める活動、民主主義そのものを技術で良くする活動だとしています[1]。

これと区別されるのが「ガブテック（GovTech）」です。行政が技術を使って自分の仕事を良くすることを指します。両者は重なる部分も多く、Code for Japan は行政職員向けの研修など、ガブテックの事業もしています[1]。中国語版ウィキペディアも、シビックテックの受け手は市民、ガブテックの受け手は政府だが、どちらも市民と政府のやり取りを強めることを目指す、と書いています[4]。

関は 2025 年のスライドで、シビックテックの「テック」は手段にすぎないとまとめています。本当の目的は、みんなが参加するより良い民主主義を実現することだ、というのです。デジタルの技術で参加の手間が大きく下がったから、新しいやり方ができるようになっただけだ、としています[7]。

国をまたぐつながり

g0v の公式 FAQ は、似た海外の団体として、英国の mySociety、米国の Code for America や Sunlight Foundation を挙げています[8]。g0v の高嘉良（clkao）は 2017 年のインタビューで、各国のシビックテック団体のネットワーク「Code for All」に台湾も入っていると語りました。g0v はゆるやかな集まりで投票できないため、別の財団が窓口を務めたそうです[9]。

日本のかたち

関によれば、地域ごとの「Code for ○○」という集まりが日本には 70 以上あります。これほど多いのは米国と日本くらいだ、と書いています（2021 年の FAQ では 90 以上とされていました）[10][1]。

10 年前には、日本人には市民としての感覚が薄く、役所任せの意識が強いから無理だ、と言われたが、日本なりの形で根づいた、と関は振り返ります。そして、シビックテックは技術やビジネスの形ではなく、上からの命令では生まれない、下からの「文化」だと論じています[11]。参加者のうちエンジニアは 3 割ほどです[1]。

新しい波 — デジタル民主主義

関は、新しい流れも報告しています。市民の団体 DD2030 から生まれた 広聴AI、スペインのバルセロナで生まれた市民参加の道具 Decidim、ブロードリスニング（大勢の声を広く聴き取って整理すること）などが登場しました。これまでのシビックテックの層とは違う、話し合いや対話に関心を持つ人たちが集まり始めた、というのです[10]。こうした市民参加の道具は、会社の事業にもなり始めています[10]。

どこが議論になっているか

  • 「市民が勝手に解決してくれる」は幻想。 関は、自治体の担当者から何度も聞いたこの期待を、13 年の経験から「幻想」だと言い切ります。Code for America が立ち上がれたのは財団からの大きな資金があったからで、Code for Japan が続いたのも、自治体向けの事業の利益を仲間の活動に回せたからだ、というのです。道具の試作はボランティアでできても、それを企業並みに運用し続けることはできない、とも書いています[10]。
  • 行政が主導すると起きること。 関のスライドは、行政が主導すると予算はつきやすい一方で、手段が目的になってしまう、市民が受け身になる、予算が切れたり担当者が異動したりすると止まる、といったことが起きやすい、としています。市民を行政の課題を解くための道具と見てはいけない、とも書いています[7]。
  • 「エンジニアの活動」ではない。 日本では「エンジニアじゃないから」と参加やリーダー役を遠慮する人が多い、と関は言います。海外の団体ではリーダーが技術者でないことも多く、まちのあるべき姿を考えることから入るべきだ、としています[10]。
  • 成果をどう測るか。 新しいサービスが生まれることへの期待が大きすぎて、仕事の進め方の改善や信頼づくりを評価する方法が無い、と関は指摘しています[10]。

Plurality の中での位置

本『Plurality』の 3-3 章「失われた道」は、「GovTech」と「Civic Tech」の運動を、「おそらく私たち自身の ⿻ への道に最も近い」ものだと書いています[2]。初期のインターネットにあった、公共のために多くの立場の人が関わる精神を、政府と市民社会のデジタルな参加を強めることで取り戻そうとする運動だ、という位置づけです。オープンソースの作り方で行政サービスを良くし、さまざまな形で市民を招き入れる、と説明しています[2]。

同じ章は先導者として、Code for America の創設者ジェニファー・パルカ（Jennifer Pahlka）、ベス・シモーヌ・ノベック（Beth Simone Noveck）、そして関治之を挙げています[2]。ただし、こうした例は大事な影響を持ったものの、g0v が台湾で持ったような国全体に見える影響は持ちにくかった、とも書いています[2]。

2-2 章は g0v を、台湾のデジタル民主主義を支える市民社会の土台の象徴として描き、その創設者たちを「市民ハッカー」と呼んでいます[12]。台湾の歩みは 台湾のデジタル民主主義 と vTaiwan の記事で扱います。
