失われた道（The Lost Dao）ってなに？

インターネットの元をつくった 1960〜70 年代の米国の研究者たちは、コンピュータで人がつながり、一緒に考え、一緒に治めることを目指しました。けれども公的な投資が細るうちに、その志の一部は作られないまま忘れられました。本『Plurality』はこれを「失われた道」と呼びます。

いま私たちがネットでログインするとき、多くの場合は大きな IT 企業のアカウントを使います。お金を払うときも、どこかの会社のサービスを通ります。でも、インターネットを最初につくった人たちは、こうした土台も「みんなのもの」として作るつもりだった、と本『⿻ Plurality』は書きます。その作られなかった道を、本は「失われた道（The Lost Dao）」と呼びます。

ひとことで言うと

いまのインターネットの元になった 1960〜70 年代の米国の研究者たちは、コンピュータで人と人がつながり、一緒に考え、一緒に治めることを目指していました。ところが、国の研究投資が細り、民間の大企業がその隙間を埋めるうちに、志の一部は作られないまま忘れられました。本人確認・支払い・データの共有といった土台です[1][2]。

本はこれを「失われた道（ダオ）」と呼び、取り戻そうと呼びかけます[1]。「ダオ」は中国語の「道」です。

たとえば

「銀河間計算機ネットワーク」（1963 年）。 米国防総省の研究機関 ARPA で、情報処理の部署を率いた J. C. R. リックライダー（Licklider）は、研究拠点どうしを結ぶネットワークを、冗談めかして「銀河間計算機ネットワーク」と呼びました。コンピュータを通じた協働と、一緒に治めることの手本にしたかったのです。彼が支えたスタンフォード大学や MIT など 5 つの大学は、計算機科学の中心になりました。支援を受けたダグラス・エンゲルバート（Douglas Engelbart）の研究所からは、マウスや、文章どうしをつなぐ「ハイパーテキスト」が生まれました[3]。

RFC（Request for Comments、意見募集）。 スティーブ・クロッカー（Steve Crocker）が始めた RFC という手続きを、本は「おそらく最初の『ウィキ』的な、非公式で主に追記型の協働の一つ」と呼びます。政府・企業・大学に散らばる人々がこれで協働し、いまのネットの通信の約束事 TCP/IP につながりました。1974 年に TCP が RFC 675 として回覧され、1983 年に TCP/IP が ARPANET の公式の約束事になりました[4]。

本によれば、「インターネット」の名は、多様な地域のネットワークがつながり合う「ネットワークのネットワーク」から来ています。政府が上から標準を決めたフランスの Minitel とは逆のやり方でした[4]。

利用者の急増。 本によれば、ウェブが公開された 1991 年から 2000 年までに、インターネットの利用者は約 400 万人から 4 億人超に増えました[5]。400 万の 100 倍が 4 億なので、10 年たたずに 100 倍以上になった計算です。

くわしく

始まりはスプートニク

本の 3-3 章によれば、流れが大きく動いたのは、1957 年 10 月にソ連が人工衛星スプートニクを打ち上げたときです。アイゼンハワー政権は、冷戦の熱を科学研究と教育に向け、国防総省の中に半ば独立した ARPA をつくりました。その代表的な計画が、リックライダーの部署でした[6]。

リックライダーは 1960 年の論文「人間とコンピュータの共生」で、機械がいずれ人間の脳を上回るとしても、その前に、人間とコンピュータが一緒に働いて進歩する長い時期がある、と書きました[6]。本は、この歴史の多くを M・ミッチェル・ワールドロップ（M. Mitchell Waldrop）の本『The Dream Machine』に拠ったと明記しています[6]。

三つの層での ⿻

本によれば、インターネットの開発の核心は、中央集権的・一本道・ばらばらの構造を、⿻（多元的）な関係と統治に置き換えることでした。それは三つの層で起こり、1990 年代初めにウェブとして合流しました[4]。

  1. パケット交換。 中央の交換台を通す代わりに、データを小分けにして網の目を流します。ポール・バラン（Paul Baran）は 1964 年の報告で、中心が多い網は安い部品でも壊れた所を迂回して攻撃に耐える、と論じました。
  2. ハイパーテキスト。 一本道の文章の代わりに、文書どうしをリンクでつなぎます。テッド・ネルソン（Ted Nelson）は「ザナドゥ計画」で、読者がいろいろな道筋で読めるようにすることを構想しました。ティム・バーナーズ＝リーのウェブがこれを広めました。
  3. 開かれた標準づくり。 政府や企業が上から決める代わりに、みんなで約束事を決めます。上の RFC と TCP/IP です。

勝利の陰の警告

パソコンとインターネットは大成功しました。本によれば、2000 年には米国人の過半が自宅にパソコンを持っていました[5]。

けれどもネルソンは警告を続けました。安全な ID のしくみが無ければ、無秩序と、国や企業による囲い込みが避けられない。商取引の約束事が無ければ、ネットの仕事の価値が下がるか、金融が独占される。安全な情報の共有と管理が無ければ、監視と情報の囲い込みが避けられない。ジャロン・ラニアー（Jaron Lanier）も、この心配を引き継ぎました[5]。

リックライダーも 1980 年の論文で、二つの未来を示しました。独占企業に支配されて力がつぶされる道と、社会全体で取り組んでコンピュータが民主主義に役立つ道です。前者で起こる害として、監視と政府への不信、独占、偽の情報、言論の土台を私企業が握ることなどを挙げました。本は、のちの巨大 IT 企業への反発（テックラッシュ）がこの警告に驚くほど似ている、と書きます[7]。

なぜ道を失ったのか

本は、リックライダー自身の見立てを紹介します[2]。

  • 右から。 「小さな政府」を掲げる考えが強まり、政府が技術に先回りしてお金を出す役割から退きました。
  • 左から。 ベトナム戦争で、軍が研究を方向づけることへの反発が強まりました。1970・71・73 年の法律の修正（マンスフィールド修正条項）で、ARPA は国防に直結しない研究にお金を出せなくなりました。
  • 世界に広がったこと。 インターネットが世界規模になると、そこに投資すべきはっきりした公的な担い手がいなくなりました。

その空白を民間が埋めた、と本は書きます。ID は Google や Facebook に、支払いは PayPal や Stripe に、データや計算の共有はクラウドの事業者に。リックライダーとネルソンが欠かせないと考えた基本の機能は、インターネットの土台に組み込まれないままでした[2]。

それでも残る「光」

それでも夢は消えていない、と本は続けます。本が挙げるのは、ウィキペディア、オープンソースのソフト、分散型のソーシャルメディア、そして台湾の g0v や、関治之の Code for Japan などの「シビックテック」（市民が技術で社会の課題に取り組む運動）です[8]。

どこが議論になっているか

  • 「Dao」は DAO ではない。 ブロックチェーンの世界の「DAO（分散型自律組織）」と見た目が同じですが、別物です。日本語版は章の題を「失われた道（ダオ）」、台湾の中国語版は「我們遺忘的道」と訳し、中国語の「道」として扱っています[9][10]。
  • 歴史の語りは一冊の本に多く拠る。 本自身が、リックライダー以後の話の多くはワールドロップの本に由来すると断っています[6]。
  • 著者たちの以前の議論。 ワイルらは 2019 年のエッセイで、インターネットの土台は、高い信頼と身元のしくみがもともと背後にある環境で育ったため、見知らぬ人どうしの信頼を築く ID の層を欠いた、と論じました。そして商用化の後、少数の巨大な企業が数十億人の ID を引き受けるようになった、と書いています[11]。シッダールトらの 2024 年の論文も、初期のネットは公的なお金と多くの人の標準づくりで治められたが、上の層は私企業に占められた、とし、ID・支払い・データ共有の開かれた約束事を提案しています[12]。
  • 版による違い。 台湾の中国語版の 3-3 章は、節の構成が英語版と違います。リックライダーの論文の年を 1979 年と書き（英語版は 1980 年）、マンスフィールド修正条項も 1973 年のものだけを挙げます[10]。日本語版も論文の年を 1979 年としています[9]。

Plurality の中での位置

2-0 章は、パソコン・インターネット・スマートフォンが、テクノクラシーにもリバタリアニズムにも収まらない「人の知能を増やす」系譜から来た、と述べて、3-3 章への伏線にします[13]。→ 三つの道

3-3 章が本拠です。前の 3-2 章で紹介した思想を、技術として実現しようとした歴史として描きます[6]。→ 一元論的アトム主義

同じ章の別の節は、日本では品質管理（PDCA・カイゼン）や鈴木健の「なめらかな社会」に、もう一つの失われた道が流れていた、と書きます[14]。

後の章もこの歴史を使います。4-1 章は ID の設計に当てはめ[15]（→ ID と人物性・デジタル公共インフラ）、6-0 章はパソコンが少数の早い使い手の共同体から始まったことを、広め方の理論に使います[16]（→ ⿻の変化の理論）。
